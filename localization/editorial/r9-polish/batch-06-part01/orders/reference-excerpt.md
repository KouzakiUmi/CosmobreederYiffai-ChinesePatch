# batch-06 参照摘录（雄猫道具与商店线）

`TomcatItems` root：雄猫对道具、装备、商店货品的解说与插科打诨。本 root 共 260 场／1,753 行，拆成 4 个 part 出工单。定向摘录自 R1 参照库；不是新设定，也不是角色模板。

## 一、谁在说话

主要是**雄猫（Tomcat）**对道具的说明，主角接话，偶尔 Mauser 或 Bossu 插一句。

- 雄猫：总部装备／生命体征支援，频率 28.880；「分析装备是我的工作」是男线自述。
- **本 root 是他最「损友」的一面**：热衷装备、先调侃再讲操作、拿道具开荤玩笑。
- 但**装备说明本身必须讲清**：怎么用、什么时候生效、有什么限制。笑点可以留，信息不能丢。

## 二、道具文本的特殊约束

1. **名称与说明成对**：道具名要能一眼认出是什么，说明补用途与限制。
2. **玩法信息零容错**：`按 DOWN + JUMP`、`命中可受伤目标才回弹`、`按 SELECT 使用` 这类条件不能改。
3. **荤双关按原文**：道具名与说明里的成人双关是原作设计（如 Pretzel／bone／meat 一类），保留功能，不净化、不额外加码。
4. **不合并不同道具**：`Swiper` 是兽、`Bumper` 是机器、`CosmoCard` 是资料卡、`keycard` 是门卡——四类不能混。
5. **商店话术带口音感但要能读**：店家与雄猫的调侃语域不同，不混成一种。

## 四、容器与结构限制（已实测）

- 剧情框：12px 字、240px 折行、每页 3 行；道具说明同理。
- 本 part 100 个 `current` 为空的 ROW 是既有合句尾行：不报漏译、不提案填充。
- 提案不得让任何行由 ≤3 行折行变成 >3 行；既有 >3 行的合句行应借机压回 3 行。
