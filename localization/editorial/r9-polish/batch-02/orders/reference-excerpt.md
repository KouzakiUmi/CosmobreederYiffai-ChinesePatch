从 R1 参照库定向摘录，供本批精校使用；带原文锚点的编辑参照，不是新设定，也不是角色模板。需要更多上下文时，按需定点查 `localization/editorial/r1/reference/` 下原文件（`characters-support.md` 的 Tomcat 段、`characters-primary.md`、`world-and-plot.md`），不要整读。

## 一、本批主要角色：雄猫（Tomcat）

### 身份与边界
- 总部装备／生命体征无线电支援，频率 28.880；「分析装备是我的工作」为男线自述。
- 猫身份有「CATS LIKE ME」自述支持，不是据名字猜物种。不补童年、年龄、外貌、学院定论。
- 与 Mauser 是总部同事、损友互揭短；与主角是支援与老熟人。熟稔称呼不自动成为师徒、亲属或恋人。

### 多面性（每面都有原文支撑，不能只取一面）
1. **热衷装备、先调侃再讲操作**：昂贵限量靴的笑点之后，仍讲清「空中按 DOWN + JUMP、命中可受伤目标才回弹」。
2. **亲近护短但不打包票**：`NO PURROMISES…BUT I'LL DO WHAT I CAN DO`（猫双关，可另试译，不要硬造「猫保证」）。
3. **起哄不等于永远从容**：牵绳玩笑被反将一军后会结巴，借写报告挂断。
4. **紧急救援不耍贫嘴**：低轨坠落时立刻核降落伞、制动器、飞船状态，无拉长音、无「喵」。

### 语域
- 现代口语、老熟人电台感；拉长音、猫双关、慌乱结巴只按该句保留，不逐字符复制。
- `GRRRL` 不足以支撑每句添「妞呜」；`PURROMISES` 也不必硬造。
- 全大写不是吼叫；`MON- ITORING`／`HAP- PENED` 是断词，不是口吃。
- **不得每句补「喵」、网络梗或暧昧**；女线的调侃头衔（如 VIRGIN BUSTER）不搬到男线。

## 二、本批同场其他角色

### Mauser（毛鼠）
- 先问候／感叹，再跨几框讲资料与操作；热心略絮叨，研究型话匣子会被打断。
- 装束类紧张与平稳技术说明交替；全大写／方括号不是持续吼叫。
- 称呼：公事称 agent 或姓名；不自称「鼠鼠／本鼠」。

### 主角
- Yiffany（伊吠妮）／Yiffai（伊吠），同一拼写兼作名与姓，不拆成两人。
- 女线熟练里也有急辩与调侃；男线认真汇报、显摆、急辩。都不写幼儿腔，不互相移植套话。
- 主角在某些场景处于变身形态（兽态／史莱姆／Kobo 装），那是当下的形态与称呼，不是永久身份。

### Bossu（波苏）
- 稳、明确、职业化；`AGENT` 是常用称呼，`OVER` 是无线电结束语，`NEGATIVE` 视动作译「不批准／不行／否」。
- 不是完全无情趣，但不因此轻浮化。
