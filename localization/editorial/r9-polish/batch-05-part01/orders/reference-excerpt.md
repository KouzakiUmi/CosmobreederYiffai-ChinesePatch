# batch-05 参照摘录（图鉴与首领资料）

`BossuDex` root：波苏对图鉴／首领／生物条目的解说。本 root 共 149 场／1,253 行，拆成 3 个 part 出工单。定向摘录自 R1 参照库；不是新设定，也不是角色模板。

## 一、谁在说话

本 root 的说话人绝大多数是**波苏（Bossu）**，内容是总部对扫描对象的资料解说；少数场合由 Mauser 或主角插话。

- 波苏：稳、明确、职业化；`AGENT` 是常用称呼。
- 这是**资料口吻**，不是当面指挥：句子可以比无线电短句更完整，但仍是口语说明，不是百科条目或说明书朗读。
- 波苏**不是全知旁白**：他讲的是总部掌握的观测与报告，判断词（`seems`／`might`／`may`）必须保留不确定度，不能升成断言。

## 二、图鉴文本的特殊约束

1. **条目名与正文分开**：本批含大量 `ui.data.*` 类名称＋说明成对条目（另有 UI 批处理），本批只处理 `BossuDex` 对白。
2. **数据书容器**：224px、最多 3 行，超限构建抛异常。比剧情框更紧。
3. **设定事实／角色评价／传闻**要分层：波苏说「据报告」「有目击」时，中文不能写成客观定论。
4. **生物描写保留原作荒诞与荤味**：这是成人向作品，生物的交配／繁殖／体液说明是正式内容，不净化、不额外加码。
5. **不补全未展开的机制**：扫描对象的行为若原文只给一半，不替他补完。

## 四、容器与结构限制（已实测）

- 剧情框：12px 字、240px 折行、每页 3 行。
- 本 part 103 个 `current` 为空的 ROW 是既有合句尾行：不报漏译、不提案填充。
- 提案不得让任何行由 ≤3 行折行变成 >3 行；既有 >3 行的合句行应借机压回 3 行。
- `LIGHTTAZER` 三种写法尚未终裁，不要单点改；失真字幕口径也未定。
