# batch-07 参照摘录（结局与开场演出）

`vsn/*/script.vsn` 是演出脚本：结局（EndingGood／EndingBad／EndingIntoShmup）、死亡结局（GameOverArea*）、开场（GameStart）。本批共 705 行，拆成 2 个 part 出工单。定向摘录自 R1 参照库与游戏内词典；不是新设定，也不是角色模板。

## 一、这类文本与对白不同的地方

1. **行首带 `text: `**：VSN 脚本的正文行是 `text: ……` 形式，`text:` 与后面那个空格属于前缀，**不能动**。提案只替换 `text: ` 之后的内容，整行前缀原样保留。
2. **CONTROL 行不是译文**：`fade`／`fadein`／`fadecut`／`rewind!`／`music:` 是脚本指令，一律不改、不提案、不算漏译。
3. **一个结局由多个演出块拼成**：`rewind!` 之后常接另一个分支块，块与块之间可以跳接。不要把两个块当成同一句连续台词去顺。
4. **被打断与信号中断大量存在**：`...`、`-`、首字母截断（`BR-`）都是刻意设计，按功能保留，不补齐、不统一。

## 四、容器与结构限制

- 剧情框与演出文本同为 12px 字、240px 折行、每页 3 行；结局文字分页更紧，不要把一行写长。
- `current` 为空的 ROW 是既有合句尾行：不报漏译、不提案填充。
- 提案不得让任何行由 ≤3 行折行变成 >3 行。
