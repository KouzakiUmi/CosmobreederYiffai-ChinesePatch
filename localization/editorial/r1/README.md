## 粗校主要处理什么

- 单句勉强能读，连起来却问答错位、指代悬空、条件断裂。
- 英文习语逐字照搬，或只改前一句、破坏下一句笑点。
- 跨框断词误当口吃；反过来把真实结巴、打断或自我改口全抹平。
- 通讯套语按普通动词直译，如把呼叫回应写成走进来。
- 主宾、否定、让步、可能性或角色关系改变；把角色说辞变成客观事实。
- 角色全部同一种腔调、科技说明公文化，或不合场景地添古风／幼儿腔。

发现记录均给原文、当前归档中文、完整短段重写建议、理由和来源。待核项单列，不当成已确认错译。即使方向对，建议稿仍可能需要改写；独立抽核对添加施事、凭空加口吃、丢失保留语气等情况也会退回。

- 原 catalog 8,973 单元／10,385 位置，加 SFW 原始来源 7,134 记录，共 17,519 来源记录。

- [语料清单](<corpus/snapshot-01/manifest.json>)与[阅读稿清单](<corpus/snapshot-01/readers-manifest.json>)保留输入哈希；[词法引用图](<corpus/snapshot-01/script-graph.json>)补充无台词 include 调用，不冒称运行时可达性。
- 代码候选只作用途盘点；图像只含现有转录范围，不代表所有位图文字已识别或重绘。
- [独立抽核](<review/spotcheck-01.md>)只覆盖明确列出的发现，不是全体提案的正式第二轮终审。
- 结构校验核 ID、输入身份、收据与字段；不证明语义一定正确，不替代后续节点回填、字宽／分页及实机验收。

本地全文语料用于审校，不并入公开补丁交付。正式精修时按[方案](<TRANSLATION_PLAN.md>)逐段裁决、二审和映射后再应用，禁止直接把粗校段落均分回原节点。
