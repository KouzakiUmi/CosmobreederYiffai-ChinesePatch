# 第一轮：连续语境中文重写与粗校口径

状态：文档整理与粗校提案阶段；不是人工终审，不回写正式译文，不进入安装包。

## 1. 目标与参考边界

中文应像人物在当前处境下自然说出来的话，而不是逐句套英语语序。先弄清整段在说什么、谁知道什么、笑点落在哪里，再写中文。

只借鉴 WoC 的执行方式：建立证据参考库 → 按连续场景出工单 → 对照全文粗校 → 逐条裁决 → 独立复审 → 数据与实机分开验证。

不搬用其西方奇幻文风、禁现代词表、敬语口径、专名、空说话人判定或 Ren'Py 标签规则。本作有太空探索、总部无线电、科技装备、变身与荒诞喜剧；现代科技词不是天然违规，角色粗口、调侃与亲疏关系须看本游戏原文。

## 2. 阅读顺序

1. 原文完整场景与控制上下文：说话者、条件、include、动作、语言标签、信息揭示顺序。
2. 有原文锚点的角色、关系和世界观参照；区分事实、人物说辞、译者推测。
3. 最新已构建归档的当前中文。正式 ledger 草稿仅用于溯源，不能把已合句后的空行报成漏译，也不能以修前草稿重复报已修问题。
4. 同场景的男女主、SFW / NSFW 对照。不能因为字面相同就把平行分支当作同一段经历。

首轮允许先从全文收集证据与问题；最终粗校总结和后续精校工单须在参考库汇合后再复核，不能先定角色模板再强行套台词。

## 3. 中文重写的单位

- 最小语义单位是完整意思，审读单位是连续对话／叙述段，不是数据库的一行。
- 同一人连续说完一句时，可在不跨控制事件的前提下调整中文语序、拆并句、提前条件、减少代词、改被动为主动、把英式习语换成自然中文。
- 对话来回须检查问答是否对得上、上一句的指代是否承接、反驳在反驳什么、后一句是否提前吃掉笑点。
- 不能为了顺口把两个人的话合成一人、把分支条件改成事实、改变动作施受、否定、程度、数量、玩法提示或剧情揭示时点。
- 不新增固定口癖、关系定论、动机、知识、粗俗程度或情绪。不要把所有角色写成同一种网络吐槽腔。
- 源文本可疑或信号失真时记为源异常／待判，不凭后文猜补缺失信息。

## 4. 本项目语域分层

| 文本层 | 中文方向 | 必须保留的区别 |
| --- | --- | --- |
| 总部无线电 | 信息先清楚，专业说明说人话 | 公事、熟人互损、紧张改口、紧急救援可以切换；大写不等于吼叫 |
| 外勤与人物对话 | 口语自然，句长与反应有节奏 | 角色资历、亲疏、主动与嘴硬、当下变身状态 |
| 演出与旁白 | 清楚流畅，配合动作与揭示节奏 | 不把 VSN 的统一 narrator 元数据当作实际发言人；原说话动作可能在演出中 |
| 图鉴、道具与任务文本 | 名称清晰，说明有层次，可保留原作诙谐 | 设定事实、角色评价、调侃和玩法说明不能混为一谈 |
| 菜单与提示 | 一眼能懂，命令与对象准确 | 按键、型号、数字、资源 ID 和脚本控制字不随文风改写 |

语言自然度是本轮核心验收项。意思基本对但中文连不上、习语生硬或角色口吻失真，仍须列为应改问题，不能一律归入无关紧要的修辞偏好。

## 5. 问题分级

- **A / 必修**：错译、漏义、施受或否定错误、人物关系错误、玩法误导、条件／揭示顺序破坏、脚本或占位符损坏。
- **B / 应改**：整段衔接不成立、逐字翻译腔、语用或笑点失效、角色口吻／称呼漂移、术语语境不一致。
- **C / 可选润色**：已有译文通顺且语义口吻成立，仅节奏、用词或重复的优化。
- **Q / 待核**：原文本身矛盾、说话人／触发条件／运行时用途尚不明。Q 是状态，不是替代 A/B/C 的低严重度，也不自动改译。

## 6. 粗校记录与覆盖

每份工单按整场景通读。每个场景均留下覆盖收据；有问题写发现，无问题写明确保留理由，未读或读不全必须标明。自动关键词命中只是线索，不等于语义审读；“进了工单”不等于“校过”。

每条发现至少记录：场景 ID、全部关联行 ID、原文完整短段、当前归档中文、建议重写段、问题类别和等级、为什么这样改、证据锚点、条件／分支、参照条目、状态。

建议译文是待复审提案，不直接覆盖原译。应用时另行形成每个实际输出节点的写入映射与 dry-run；不能直接把段落提案按行数平均切回脚本。

## 7. 本轮保护边界

- 原文、稳定 ID、来源哈希、归档和分支身份不变。
- 当前控制命令、说话人、include、动作、按键与动态占位符不因文笔调整而修改。
- 只有同语境且有证据的专名裁决才可能成为自动规则；多义词与语气短句不作全局替换。
- code 候选先核玩家可见用途；未证实不强行翻译。图像转录只作文本粗校，不冒充图片重绘或全图 OCR。
- 全文语料范围、去重方法、已读场景／行数、待核用途和排除项分别统计，不用“100%扫描”冒称“100%精校”。
- 后续才安排整段精修、二审、实际节点回填、字体／排版验证与实机检查。本轮不更改正在使用的补丁。
