# R3 角色名：音义与人物气质规则

用户已授权按姓名感、物种／词义双关、人物气质统一调整全部角色人名。不是把每个名字强行塞进动物字，也不是因未找到作者释名就拒绝一切中文创译。

## 判定层级

1. 原文角色证据：物种、自报、姓名／姓氏、昵称、称号、揭示时点。
2. 可核语言事实：普通词义、跨语词根、可机械验证的反写；军武同名不自动证明作者意图。
3. 中文编辑取舍：按规则设计音义结合译名，明确这是本地化创译，不冒称官方释名。
4. 名字本义与人物分类分开。例如 Gepard 可按名字义译“猎豹”，而角色物种证据仍仅记录原文明示的猫，不能由译名反定亚种。
