## 目标与约束

- 修复特殊语言字形不可见、紧凑字段笔画碰撞、断行／显露／分页完整性。
- 补齐SFW独立来源翻译、审校VSN碎句，落实分档图片工单。
- 中文尽量使用10／12px；几何确实受限时允许8px，不用虚报advance、裁切或静默截尾掩盖问题。
- 从冻结r27增量构建独立候选，不覆盖旧归档／发行目录，不安装、不启动可能访问真实存档的游戏。

依据：[前一轮审计](<../../../docs/font-layout-audit-20261025/审计报告.md>)。

## 实施分工

| 范围 | 输出目录 | 责任与接口 |
|---|---|---|
| 断行／显露核心 | core | PixelLayout、DialogueGrid、DialogueWrap、SubtitleLayout；必要时精确amn增量patch |
| 特殊语言 | pattern | StoryFont12、PatternSymbols；保留Fox／HardFox可读性语义 |
| 姓名／存档／道具 | compact | 局部字段／字体与消费链；保留原存储和菜单选择结构 |
| SFW资源 | sfw | 独立源身份ledger与内存重建API，不套用PAK行号 |
| VSN审校 | vsn | 派生合句及未译续行，保留演出控制行 |
| 固定图片 | images | 分档原图、逐字候选、原像素保护、逐帧与Alpha门禁 |
| 其余UI | scenes | Ew、地图、卡牌、成就和结算资料等已定位消费者 |
| 集成 | integration | 增量归档、字体补字、资源组合、验证与交付台账 |

各组件机器清单声明源码、精确target pins、纯资源API和可复现测试。总构建器负责同class合成、归档级资源覆盖顺序和失败门禁；不同组件不得相互覆盖文件。

## 验收层次

1. 冻结来源与字库／图片身份；未知来源不套用。
2. 纯度量、文本守恒、禁则、码元上限与全部显露索引。
3. 最终归档真实class CPU调用、glyph-run／顶点／像素及事件／页队列。
4. 图片逐不同帧、深浅底、非文字像素保护与来源hash。
5. 独立交叉复核与完整目标组合；未过项逐条保留。
6. 真正窗口的GPU／CRT／父clip／全部输入仍需另做受控实机验收，不能由CPU测试冒充。

本次已完成以上1–5层限定范围验收；第6层明确未执行。候选1失败、各组件早期失败和检查器假设修正均保留，不能将CPU合成图当实机截图或把候选译文称为人工approved。详见[完整结果及未验范围](<优化结果.md>)。
