# 公开译文贡献快照

该目录由[导出工具](<../../tools/export_translation_snapshot.py>)从本地完整工作ledger生成，不包含原游戏原文上下文、嵌套输入证据、本机来源路径和模型交接备注。它保留译文贡献和草稿/未译状态，供阅读、协作和差异跟踪。

- [zh-CN.jsonl](<zh-CN.jsonl>)：8,973条稳定ID记录，8,146条非空草稿、827条未译；不是正式全量精校。
- [dialogue-joins.jsonl](<dialogue-joins.jsonl>)：956组已合并的译文及其哈希，不含原文成员列表。
- [layout-short-overrides.jsonl](<layout-short-overrides.jsonl>)：排版短文案贡献；不含旧目标原文。
- [snapshot.json](<snapshot.json>)：版本、计数和输出哈希。

**本快照不是旧全量构建的完整输入ledger。** 去掉的原资源位置与成员身份需要维护者用匹配的原游戏及本地研究输入核对，不能把该快照复制回旧工作ledger后绕过来源门禁。翻译保留原作权利，不授予原游戏内容的再分发权；见[项目声明](<../../NOTICE>)。
