# alpha0.3（测试版）

第三个公开的差分安装器版本，安装器协议与界面沿用 alpha0.1 不变。这一版换的是**内容**：在 alpha0.2（candidate47）之上并入排版与专名八批（batch-19～25，内容基线 `r9-polish-candidate55`），并把「折行不切词」从插断行符推进到按真实容器改写文案。仍是非官方、未签名、**未做实机验收**的测试版。

## 下载

- `CosmobreederYiffai-alpha0.3-setup.exe`：Windows 独立安装器，内置 Python，无需另装。
- `CosmobreederYiffai-alpha0.3-python.zip`：Python 3.12 源码运行版，同一份差分负载与完整许可文本。
- `SHA256SUMS`：发行资产与内部负载的校验清单（`sha256sum -c SHA256SUMS` 全部 OK）。
- `acceptance.json`：本版封签记录（归档 SHA、40 批台账状态、读回结果、未验证项清单）。

两种包都依赖**你自己取得的、匹配清单 SHA-256 的原游戏文件**；发行物不含完整替换归档。安装器只处理识别得到的原版 JAR（SFW）或 JAR+PAK（官方 NSFW 补丁），未知版本拒绝修改，也不提供强制覆盖。

## 相对 alpha0.2 的变化

排版侧（八批，1,421 个操作，台账总数 2,179）：

- batch-19／21：中文引号，含多行卡面值。
- batch-20：Fenfen 统一为「芬芬」（148 处）。
- batch-22：续行不以标点开头，修 57 行；其余 1,074 行因会改变分页未做。
- batch-23：插 U+2028 修折行切词 1,163 行（断词 1,393→197 处，显示行数不变）。
- batch-25：改写 96 行文案让 240px 折行的断点不落实词中间；按无线电容器复核后保留 22 行、回退 73 行。发行态引擎实测（加载候选归档里自己的 `DialogueWrap`／`PixelLayout` 渲染，二字组 ≥30 频次口径）：96 行范围故事框 92→65 处、无线电 69→54 处；全库故事框 349→322 处；保留行两容器残留断点 0；故事框分页不变。
- **容器归属已按调用链反编译核实**：`<TomcatItems.*>`／`<BossuDex.*>` 物品说明走 150px 无线电容器（每行 15 汉字），不是 240px 故事框；验收按真实容器取（`localization/editorial/r9-polish/batch-25/simulated-render-research.md`）。

文本侧：无新增精校批次（R9 三十四批已在 alpha0.2 落地）。

## 仍需注意

- 安装/还原前关闭游戏与其它 Java 程序；进程守卫检测到 Java 会拒绝修改。
- 装过 alpha0.1／alpha0.2 的，先用对应旧安装器还原，再用本版；不能覆盖旧记录。
- 多文件安装不是硬件断电意义的原子事务；异常中断有 journal 恢复路径，但不保证任意存储故障。
- 别删备份，别对未知文件强制操作。

## 验证边界

已做：candidate55 的 17 步 CPU 回归全部 exit 0；40 份逐批 gate 全部 `verified_for_application` 且台账/裁决表哈希与 gate 记录相符；明文读回 2,179 个操作 0 问题；差分重建对冻结目标**逐字节相等**；安装器 EXE 的 `--verify-payload` 与 `--licenses` 通过（构建时与构建后独立复跑各一次）；推送前独立只读核验（台账 23 操作全量核对、封签哈希实算、计数管线复算 322／292）无阻断项。

未做：**真实安装、卸载、启动游戏、GPU/CRT/裁剪渲染、存档读写**。这些必须由人工实机验证，本版任何材料都不能替代。
