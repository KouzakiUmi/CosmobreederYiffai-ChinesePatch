# alpha0.2（测试版）

第二个公开的差分安装器版本，安装器协议与界面沿用 alpha0.1 不变。这一版换的是**内容**：文本精校从「批次定义内部分完成」推进到「可译文本全部过完」。仍是非官方、未签名、**未做实机验收**的测试版，不是稳定版或游戏本体。

## 下载

- `CosmobreederYiffai-alpha0.2-setup.exe`：Windows 独立安装器，内置 Python，无需另装。
- `CosmobreederYiffai-alpha0.2-python.zip`：Python 3.12 源码运行版，同一份差分负载与完整许可文本。
- `SHA256SUMS`：发行资产与内部负载的校验清单。
- `acceptance.json`：本版封签记录（归档 SHA、34 批台账状态、读回结果、未验证项清单）。

两种包都依赖**你自己取得的、匹配清单 SHA-256 的原游戏文件**；发行物不含完整替换归档。安装器只处理识别得到的原版 JAR（SFW）或 JAR+PAK（官方 NSFW 补丁），未知版本拒绝修改，也不提供强制覆盖。

## 相对 alpha0.1 的变化

文本侧：

- R9 全正文精校三十四批全部落地（candidate47），**2,698 场／12,552 行**，占全库 2,989 场的 90.3%、13,494 行的 93.0%。
- 剩下 291 场不进补丁：287 场是 Java class 里的键名字符串（`"Buff.desc"` 这类，不面向玩家），4 场是位图资源，属图像本地化工艺线。
- 新增三批清理：术语与按键名残留（batch-15）、补 batch-01 漏出的 21 场（batch-14）、专名统一 FENFEN（batch-16）、术语补漏「干员」与 LIGHTTAZER（batch-17）。
- 关键裁决：VAULT 统一「金库」、DEPOT「仓库」、NAVMAP「导航地图」、LIGHTTAZER「光击枪」、FENFEN「芬芬」、按键名一律保留英文原文。

排版侧（本轮新增复核，`localization/editorial/r9-polish/tools/audit_containers.py`）：

- 用候选归档里的真实字模，按引擎的真实规则逐个量了硬切容器：角色卡 96 个值（16 列 × 128px、15 行）、成就 60 个值（30 列、2 行）、数据书与结局数据块 200 个值（224px、3 行），**全部 0 超限**。
- 合句留下的 1,709 个空尾行中，1,701 个中文超过 240px，由 `story12` 自动折成两行、两行都有字；8 个是败北提示的短句（228–236px），一行放得下且不接续对话；0 个短到真的空一行。

## 仍需注意

- 安装/还原前关闭游戏与其它 Java 程序；进程守卫检测到 Java 会拒绝修改。
- 装过 alpha0.1 或 r23–r27 旧测试版的，先用对应旧安装器还原，再用本版；不能覆盖旧记录。
- 多文件安装不是硬件断电意义的原子事务；异常中断有 journal 恢复路径，但不保证任意存储故障。
- 别删备份，别对未知文件强制操作。

## 验证边界

已做：17 步 CPU 回归（编译、无线电、核心、像素布局、对话网格、折行、continue、字幕、图样、双档结局、场景、story12 生命周期、compact 全套）全部 exit 0；34 份逐批 gate 全部 `verified_for_application` 且台账/裁决表哈希与 gate 记录相符；明文读回 758 个操作 0 问题；差分重建对冻结目标逐字节相等；安装器 EXE 的 `--verify-payload` 与 `--licenses` 通过。

未做：**真实安装、卸载、启动游戏、GPU/CRT/裁剪渲染、存档读写**。这些必须由人工实机验证，本版任何材料都不能替代。
