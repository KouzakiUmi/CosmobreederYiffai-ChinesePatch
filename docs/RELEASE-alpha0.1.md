# alpha0.1（预发行）

首个公开源码与差分安装器版本，功能基线为 `r27-story12-shaderfix-test5`。这是非官方、未签名、翻译与实机验收尚未完成的alpha，不是稳定版或游戏本体。

## 下载

- `CosmobreederYiffai-alpha0.1-setup.exe`：Windows独立安装器，无需单独安装Python。
- `CosmobreederYiffai-alpha0.1-python.zip`：Python3.12源码运行版，包含同一差分负载、应用代码和完整许可文本。
- `SHA256SUMS`：对应发行资产及内部负载校验清单。

两种安装器都依赖用户自行取得的、匹配清单SHA-256的原游戏文件；发行物不携带完整替换JAR/PAK。原版仅处理游戏JAR；检测到匹配官方补丁时处理JAR与PAK两项。未知版本拒绝修改，不提供强制覆盖。

## 主要变更

- 独立原生12px中文剧情字体；开场、全宽剧情和结束叙事报告约20字换行，保留原动画、分页和事件。
- 无线电10px/约15字，Continue10px/约8字，道具classic8，存档保留原布局。
- 保留956组续句合并，并修复窄栏分页完成时可能漏末字的问题；本体与官方补丁来源差异不强套。
- 修复新字库透明白像素被原游戏红通道着色器视为笔画、导致实心黄色字块的问题。
- 新的源依赖COPY/XOR差分协议、源/负载/目标完整哈希门禁、备份、异常回滚及中断恢复；应用日志与状态不包含存档内容。
- 公开原创补丁源码、去私有溯源/原文上下文的译文贡献快照和完整第三方许可。历史完整游戏输入、构建缓存与研究快照保留本地，不进入仓库。

## 使用与回退

退出游戏并自行备份存档。装过r23–r27等旧测试版时，先用对应旧安装器还原，然后安装本版。安装/还原前关闭游戏和其他Java程序；进程守卫采取保守策略，检测到Java时会拒绝修改。

安装器只能覆盖识别的源文件，不能覆盖任意用户修改。如果遇到未知当前文件或损坏状态，停止并保留备份供人工核对。多文件安装不是硬件断电意义的原子事务；进程异常与受测中断有journal恢复路径，但不保证任意存储故障或断电都能自动恢复。不要删除备份或对未知文件强制操作。

## 验证与限制

差分协议边界、负载篡改拒绝、真实归档两档安装与精确SHA还原、进程异常回滚、GUI及完整许可证查看均纳入发行验证。它们不代表已完成游戏GPU/CRT/裁剪与完整流程实机验收。

公开译文快照8,973条，其中8,146条有草稿、827条未译；不等于完成精校。英文/变体文本仍可能保留。旧全量r27目标构建依赖本地研究中间物，公开源码目前不能从干净克隆一键重建整个目标；alpha差分封装和安装器源码可独立阅读、测试并在准备本地输入后构建。
