# 场景连读审查

审查对象：当前九份可编辑译文，共 16,545 条。按独立播放场景和界面记录核对，包含单行台词和两档位、男女路线各自的变体。只改译文目标列。

## 判定规则

- **先通读，再改。** 看清谁在说、回应哪句、现在看得到什么。人物对白读出声也要容易听懂；报告、提示和界面用自然明白的中文，不把叙述硬改成人物台词。
- **按播放关系判断，不按表格相邻判断。** 同场景连读但不把一条分支接到另一条上；原版切到新画面、来电被打断或故意把包袱留到下一屏的，保留该节奏。中间有条件、特效、镜头、人物或动画指令时，不随意移动信息。
- **同义台词跨档位同步。** 同名场景不等于同一稿，先核源文与控制行。原版任务目标、角色身份、线索和机制有区别时，保留差异。
- **覆盖口径。** 场景表列出的条目，经全段对读才计入。完全相同的源文、目标和控制序列可一起判定；不同就分开审。UI 按道具、任务记录、界面组对读，不按词典的存储顺序连句。

场景视图：[scene_audit.py](../tools/scene_audit.py)，例如 `python -X utf8 tools/scene_audit.py show '^vsn:[fm]_GameStart$'`；画面和分支控制行用 `│` 标识，`∅` 是译文空尾。脱离实际游玩时，脚本内顺序可核实；分处不同资源的触发先后、实际自动折行与画面停留仍需实机查看。
